# Source assets

Folder ini menyimpan aset asli yang diberikan pemilik proyek.

- `event-brand/` berisi logo event sumber.
- `logo-ecosystem/` berisi logo ecosystem sumber.

Versi WebP yang sudah dioptimalkan untuk website berada di:

- `public/event-brand/`
- `public/logo-ecosystem/optimized/`

Aplikasi hanya mereferensikan versi teroptimasi agar payload publik tetap ringan.
