# AI Co-Creation Lab - Web Update Pack

Paket ini menambahkan dua pekerjaan pada website `event.dekatlokal.com`:

1. Memperbarui timeline pada laporan **Mini Project Canvas**.
2. Menambahkan halaman **Sponsorship Proposal** dengan flipbook 24 halaman.
3. Menambahkan tombol unduh Mini Project Canvas dalam format PDF bergaya slide.

## Cara pakai

1. Ekstrak seluruh paket ke root repository website event.
2. Buka Codex atau coding agent dari root repository.
3. Kirim isi `CODEX_ONE_SHOT_UPDATE_PROMPT.md`.
4. Agent wajib membaca semua file pendukung sebelum mengubah kode.
5. File PDF siap pakai sudah tersedia dan cukup disalin ke folder `public/downloads`.
