# Report Content Lock

Dokumen ini menetapkan aturan mutlak terhadap isi tiga laporan GEP Week 1.

## Aturan utama

1. Isi laporan tidak boleh diringkas.
2. Isi laporan tidak boleh diparafrasekan.
3. Judul section tidak boleh diganti.
4. Angka tidak boleh diubah:
   - 20 mahasiswa;
   - 5 UMKM;
   - 5 tim;
   - 5 prototype sistem digital;
   - Senin, 10 Agustus 2026;
   - 13.00–16.30 WITA;
   - Balai Besar Pelatihan Komunikasi dan Digital Makassar.
5. Nama stakeholder tidak boleh ditambah atau dihapus tanpa instruksi pengguna.
6. Status tidak boleh dinaikkan menjadi capaian apabila masih berupa target.
7. Evidence link tidak boleh dikarang.
8. Data pribadi tidak boleh ditambahkan.
9. Klaim partnership tidak boleh diperkuat melebihi label yang telah diberikan.
10. Isi production harus berasal dari tiga file laporan Markdown dalam paket ini.

## Yang boleh diubah Codex

Codex hanya boleh:

- mengubah format Markdown menjadi object TypeScript;
- menyesuaikan bentuk data dengan type project;
- menambahkan ID section;
- membuat slug;
- membuat helper rendering;
- memperbaiki escape string;
- membuat komponen presentasi;
- menyesuaikan path import.

Codex tidak boleh mengubah isi substantif.
